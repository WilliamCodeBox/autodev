# ADR-0004: 上下文预算作为硬工具层拦截

## Context

LLM 在长任务中倾向于忽略上下文预算限制，不会自我拒绝超出上下文窗口的内容。如果让 LLM 自行管理上下文预算，很容易出现超出模型上下文窗口导致截断或退化的问题。

## Decision

上下文预算实现为硬工具层拦截。evaluateReadGate 是一个纯函数 —— 接受当前使用量和预算参数，返回 green/amber/red。red 区由工具层直接拒绝读取，不依赖 LLM 的"判断力"。三区设定（green/amber/red）基于模型窗口百分比，支持不同上下文大小的模型（200K/256K/1M 窗口）按比例适配。

## Consequences

- 优点：可靠 —— 纯函数测试，不依赖 LLM 自我评估
- 优点：透明 —— 三区状态在阅读前就判定，不给 LLM 讨价还价机会
- 优点：通用 —— 按百分比计算，适应不同模型窗口大小
- 代价：硬拦截可能过于保守，有时 LLM 需要少量越界完成当前任务
